Accessibility

This statement is about departed.lightmorphic.com. It was written after testing, not before.

What we aim for

We aim to meet the Web Content Accessibility Guidelines 2.1 at level AA. We believe this site meets that standard, with the exception noted below.

What has been done

  • Every piece of text was checked against its background for contrast, in both the light and the dark version of the site, and all of it passes AA.
  • The page works with the keyboard alone, and the focus outline is always visible and never removed.
  • There is a skip link to the main content as the first thing you reach.
  • Headings run in order, the page declares its language, and the drawings are marked as decoration so a screen reader passes over them rather than describing shapes.
  • Every animation stops if your system is set to reduce motion. Nothing is hidden when it stops, and nothing depends on movement to be understood.
  • The layout was walked from 320 pixels wide up to 1600 in small steps, and never scrolls sideways or overlaps.
  • Colour is never the only way something is signalled.
  • Text can be resized in the browser without anything being cut off.

What is known not to work

  • The install instructions include blocks of configuration that scroll sideways on a narrow screen. That is the nature of the content, and each block is reachable and readable with a keyboard, but it is not comfortable on a phone. If you would like the setup instructions in another format, ask and we will send them.
  • The site has not yet been tested by a person who uses a screen reader daily. Automated checks and manual keyboard testing are not the same thing as that, and we would welcome the correction.

The Departed software

The dashboard you install follows the same rules as this site, but it has had less testing. If you hit a barrier in the program itself, that is a bug worth reporting, and it will be treated as one.

Telling us about a problem

If something here is unusable for you, email complaints@lightmorphic.com. Say what page you were on and what happened. We aim to reply within five working days and to say plainly whether we can fix it and when.

This statement was prepared on 5 September 2026, based on testing carried out on that date.
