Cookies

This website sets no cookies and does no tracking.

This website

No cookies are set here, of any kind. Nothing is written to your browser's storage, nothing follows you between pages, and there is no consent banner because there is nothing to consent to.

The Departed software

The program you install on your own machine does set one cookie, on your own machine, so that signing in to its dashboard lasts rather than being asked for on every page. It is named departed_session, it holds a signed marker and no personal data, and it expires after 30 days. Signing out removes it, and so does changing the dashboard password.

Neither of those reaches us. Departed is software you run, not a service we operate.
