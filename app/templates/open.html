Open a sealed archive

Somebody left you a file and a passphrase. Put both in below and you will get what is inside.

This happens entirely in your browser. The file is not uploaded, the passphrase is not sent, and nothing here is recorded. You can turn off your internet connection first if you would rather, and it will still work.

If you would rather not use this page

The file is an ordinary encrypted file, made the way OpenSSL makes them. Any computer with OpenSSL on it, which is most Macs and every Linux machine, will open it with one command. You do not need this program or this page at all.

openssl enc -d -aes-256-cbc -pbkdf2 -iter 600000 -md sha256 \
  -in departed-sealed.enc -out inside.zip

It will ask for the passphrase. What comes out is a normal zip file that any computer can open.
