The timing

As you have it set: a check-in email every {{ days(cfg.checkin_interval.total_seconds() / 86400) }}, then {% if cfg.reminder_count %}{{ cfg.reminder_count }} reminder{{ 's' if cfg.reminder_count != 1 }} {{ days(cfg.reminder_interval.total_seconds() / 86400) }} apart{% else %}no reminders at all{% endif %}. If you answer none of them, your files go about {{ days(cfg.days_to_fire) }} after your last check-in.

All three are yours to choose. Fractions are allowed, so 0.01 is about a quarter of an hour, which is handy for testing. Nought reminders means it fires one interval after the first email, which is quick, so think before you set that.
